# NLTest


NLTest 是yyll新的框架（搭配不同测试子项（Userstep\Step下的VI）形成不同配方），部分依据Ytester开发，又不同于Ytester。比如他是开源的，单线程的，使用RUNVI（会有根阻塞），使用接线面板上的控件，更像TestStand。

NLTest is a new framework developed by YLL (with different test sub items (VI under Userstep \ Step) to form different formulas), partially developed based on Ytester but different from Ytester. For example, he is open source, single threaded, using RUNVI (with root blocking), using controls on the wiring panel, more like TestStand.
