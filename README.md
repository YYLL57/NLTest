# NLTest


NLTest 是yyll新的框架（搭配不同测试子项（Userstep\Step下的VI）形成不同的测试配方）。部分依据了Ytester开发经验（序列编辑器），使用Ytester同样的变量及表达式引擎库，又不同于Ytester。比如他是开源的源码，单线程的，使用RUNVI（会有根阻塞问题），使用接线面板上的控件配置输入输出，更像TestStand。目前还在完善中。

NLTest is a new framework developed by yyll, which combines different test sub items (VI under Userstep \ Step) to form different test formulas. Partially based on Ytester development experience (sequence editor), using the same variables and expression engine library as Ytester, but different from Ytester. For example, it is open-source and single threaded, using RUNVI (which may have root blocking issues) and configuring input and output using controls on the wiring panel, more like TestStand. At present, it is still under improvement.
